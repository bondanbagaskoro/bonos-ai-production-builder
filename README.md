# BONOS AI Production Builder — GitHub Pages landing page

This is a static project-information site, not the working production builder or a live SIWC integration.

## Publish to GitHub Pages
1. Sign in to GitHub as `bondanbagaskoro`.
2. Create a **public** repository named `bonos-ai-production-builder` (if the name is available).
3. Upload `index.html`, `style.css`, `script.js`, `privacy.html`, `terms.html` into the **repository root** (not inside a subfolder).
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
6. Wait for Pages to publish and verify the site. Expected URL (not yet verified): `https://bondanbagaskoro.github.io/bonos-ai-production-builder/`.
7. Check that Privacy and Terms links work before using the URL in an application form.

Do not upload `.env`, OAuth client secrets, API keys, backend data, or private user files to this public repository.

## Important
SIWC and AI image generation are **not active**. GitHub Pages hosts static content only. It cannot safely host a Node.js backend or secret credentials.
